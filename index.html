Web Applications

Build full-featured web apps for any scale—from MVPs to enterprise platforms with rich templates, dynamic routing, and powerful middleware.

  • ECR templates and layouts
  • Sessions and CSRF protection
  • Composable before/after filters

APIs

Design fast, stateless APIs that plug into your existing front‑ends and microservices.

  • Native JSON handling
  • All HTTP verbs, including QUERY
  • No forced ORM
Open the Cookbook →
src/api.cr
{% highlight ruby %} require "kemal" require "json" before_all do |env| env.response.content_type = "application/json" end post "/users" do |env| name = env.params.json["name"].as(String) { id: User.create(name).id, name: name }.to_json end Kemal.run {% endhighlight %}

Real‑time

Use WebSockets to build live dashboards, chats and collaboration tools with minimal boilerplate.

  • WebSockets built in
  • Fibers for concurrency
  • No extra dependencies
Open the Cookbook →
src/chat.cr
{% highlight ruby %} require "kemal" SOCKETS = [] of HTTP::WebSocket ws "/chat" do |socket| SOCKETS << socket socket.on_message do |msg| SOCKETS.each { |s| s.send msg } end socket.on_close { SOCKETS.delete(socket) } end Kemal.run {% endhighlight %}

Get started

Up and running in a minute.

01Create a project
$ crystal init app my-app
$ cd my-app
02Add Kemal to shard.yml
dependencies:
  kemal:
    github: kemalcr/kemal
03Install and run
$ shards install
$ crystal run src/my-app.cr
→ http://localhost:3000
